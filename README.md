# Cognitive Brown Bag 2026-09-30

This repo contains materials related to a talk that Rick Gilmore gave on September 30, 2026 in the Cognitive Area brown bag.

## About

The talk is a Quarto (.qmd) file that renders into HTML slides using the RevealJS framework.

The source file is `index.qmd`.

The rendered talk is in `docs/`.

Github Pages hosts the slides as a web site at <https://gilmore-lab.github.io/2026-09-30-cognitive-bbag/>.
